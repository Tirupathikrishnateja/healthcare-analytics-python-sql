# Healthcare Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing healthcare data through an interactive dashboard developed using Microsoft Power BI.

The dashboard is designed to organize healthcare-related information into visual reports, helping users explore operational metrics, identify patterns, and understand trends across the available dataset.

The project demonstrates the use of business intelligence and data visualization techniques to transform structured healthcare data into an accessible reporting solution.

## 🎯 Project Objectives

- Present healthcare data through interactive visualizations.
- Monitor healthcare-related indicators and performance metrics.
- Explore trends and comparisons across the dimensions available in the dataset.
- Improve the accessibility and interpretation of healthcare information.
- Demonstrate practical Power BI reporting and dashboard design skills.

## 🚀 How to Open the Dashboard

1. Download the `.pbix` file and any required source data files from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the Power BI report.
4. If the report cannot find its source data, update the file path or data-source settings.
5. Refresh the data if required.
6. Explore the dashboard visuals and interactive filters.
